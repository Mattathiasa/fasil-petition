# Fasil Kenema FC Petition

Amharic-language petition site for Fasil Kenema FC supporters, calling for
club chairman Ato Abiyot Birhanu to step down. Single-page app: the petition
statement, a signature form, and a running signature tally.

**Stack:** React + Vite, Firebase (signatures/tally storage).

## Structure
- `src/App.jsx` — main page
- `src/firebase.js` — Firebase client config
- `src/components/` — UI components
- `src/hooks/` — data hooks
